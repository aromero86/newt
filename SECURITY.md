# Security

If you find a vulnerability in newt, its packages or newt-monitor, please do not open a
public issue. Report it privately through
[GitHub's security advisories](https://github.com/aromero86/newt/security/advisories/new):
what it is, how to reproduce it, and which versions it affects.

You will get an answer within a week. Once it is fixed and released, the advisory is
published with credit to you, unless you would rather not be named.

Only the latest published version of each `@newt-kit` package receives security fixes.
